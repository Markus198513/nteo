06 / FAQ

Frequently asked questions

Can I order cut vinyl without installation?

Yes. You can order ready-cut graphics supplied with application tape for self-installation.

Can you come and apply the stickers?

On-site application can be arranged for glass, shopfronts, doors, walls and suitable vehicle surfaces. Location and installation terms are confirmed for each project.

Which file formats can I send?

Vector PDF, SVG, EPS or AI files are preferred. You can also send PNG, JPG or a photo so we can check whether the artwork is suitable for cutting.

Can you help if I do not have finished artwork?

Yes. Send a description, text, logo or reference image. We can discuss artwork preparation and confirm any design fee before starting.

Do you only work in Limassol?

No. We accept enquiries across Cyprus, including Paphos, Nicosia and Larnaca. On-site installation is arranged by location.

Which stickers are suitable for outdoor use?

We select the film based on the surface, sun exposure, moisture and expected service life. We will recommend a suitable option after reviewing the application.
